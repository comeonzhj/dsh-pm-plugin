如何添加索引源

索引是静态 JSON，DSH 直接读取；市场只负责展示与安装，不经过任何中间服务。

1

打开自定义插件市场

插件页 → 实验性插件旁的更多 → 打开 自定义插件市场。之后会出现「发现」标签页。

2

添加索引源

进入「发现」→ 添加索引源 → 粘贴上面的索引 URL。每个索引源属于当前 profile。

3

浏览并安装

卡片显示推荐版本与来源；安装前请在确认框中核对 npm 包或 Git 提交，市场为第三方内容。

收录插件

首期收录 4 个插件。版本列表按需精选，均声明 DSH 兼容范围；完整字段见 index.json。
